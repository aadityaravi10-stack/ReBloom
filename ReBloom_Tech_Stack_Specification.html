Tier 2 Generative AI Architecture & Prompt Engineering

🤖 Google Gemini 1.5 Flash API

  • Endpoint: https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent
  • MIME Output Configuration: application/json enforcement for predictable parsing.
  • Prompt Engineering Pipeline: Ingests previous role, gap duration (months), reason (maternity/caregiving), and target track.
  • Output Schema: Generates structured JSON:
    • resumeSummary: Empowering professional summary with zero gap apologies.
    • interviewScript: 60-second STAR framework response to "Explain your gap".
    • transferableSkills: 4 mapped corporate competencies (crisis containment, budgeting, agile multitasking).

🛡️ Zero-Latency Fallback AI Engine

  • Deterministic Coaching Engine: Built directly into aiService.js to protect live demos.
  • Rate-Limit Immunization: If internet connectivity drops or API quotas are exceeded, the engine seamlessly switches to client-side heuristic coaching without failing.
  • Contextual Tailoring: Dynamically calculates tenure strings and gap duration ratios in milliseconds.
  • Privacy First: Candidate break details are processed ephemerally without third-party tracking.

Tier 4 Custom Algorithms & Service Layer

🎯 Smart Match Algorithmic Engine

File: src/services/jobsService.js

  • Skill Vector Analysis: Evaluates candidate existing skills against open cohort requirements:
    candidateSkills.some(cs => cs.toLowerCase() === reqSkill.toLowerCase())
  • Multi-Dimensional Filtering: Filters by Work Model (Remote, Hybrid, Onsite), Department, and Break Duration (1+, 2+, 3+ years).
  • Cohort Recommendation: Powers the dynamic "Smart Comeback Match" banner on the candidate dashboard.

🏢 Vector Brand Rendering Engine

File: src/components/common/CompanyLogo.jsx

  • Direct Vector SVGs: Embedded high-fidelity vectors for Microsoft Leap, Intuit Again, Deloitte Encore, Razorpay, Target Elevate, and Infosys Restart.
  • Zero Network Dependency: Logos render instantly offline without external CDN latency or broken image tags.
  • Dynamic Adaptive Fallback: Parses custom employer image URLs or generates dynamic 2-letter monograms with gradient backdrops.
